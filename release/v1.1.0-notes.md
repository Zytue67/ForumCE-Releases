# ForumCE v1.1.0

ForumCE v1.1.0 adds **Windows 10/11 x64 support** to ForumCE Connect while keeping support for Apple Silicon and Intel Macs.

## What's new

- ForumCE Connect for Windows 10/11 x64
- Automatic TI-84 Plus CE COM-port detection on Windows
- Windows-local app data/token storage
- Windows TI Connect CE launching support
- Cross-platform USB reconnect handling
- Packaged desktop builds include Python and required dependencies

Windows support was tested with a physical TI-84 Plus CE, including forum loading, posts/replies, direct messages, reactions/notifications, timestamps, and USB reconnecting.

## Calculator client

The calculator client is unchanged from v1.0.0, so the three calculator files remain version 1.0.0 and keep their existing verified SHA-256 hashes.

## Downloads

Choose the ForumCE Connect build for your computer, then use TI Connect CE to install the three ForumCE calculator files if needed.
